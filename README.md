
# Fiszki App  
### Aplikacja do nauki języka angielskiego

---


## Technologie
- Android Studio  
- Java 11  
- XML Layouts  
- SQLite  


## Kompatybilność
| Parametr | Wartość |
|-----------|----------|
| Typ aplikacji | Mobilna (Android) |
| Minimalna wersja Android | 10 (API 29) |
| Docelowa wersja Android | 15 (API 36) |
| compileSdk | 36 |
| Język projektu | Java 11 |
| Testowano na | Android Emulator (Pixel 6, Android 12) |
| Urządzenia | Telefony |
| Orientacja ekranu | Pionowa |
| Uprawnienia | Brak specjalnych wymagań |
